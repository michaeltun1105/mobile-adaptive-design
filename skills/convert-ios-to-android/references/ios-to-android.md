# iOS → Android translation and SF Symbol replacement

### iOS → Android translation (when the original is an iPhone design)
1. Delete iOS status bar and home indicator. 2. Resize to 412 (test 360). 3. Add Android status bar + gesture (or 3-button) bar. 4. Tab bar → Navigation Bar (≤ 5 items; move profile/settings to the top app bar; a primary action may become a FAB). 5. Nav bars → Top App Bars: title **left-aligned**, child views use the **up arrow**, full-screen modals use **close**; iOS text buttons (Cancel/Done) usually become icons; iOS large titles → large/flexible app bars. 6. iOS sheets → full-screen dialog app bar or bottom sheets; action/activity sheets → bottom sheets; alerts → dialogs. 7. Segmented controls → **tabs** when they switch content categories (attached to the app bar), **connected button group** when they switch a view, filter or sort (M3 Expressive; segmented buttons no longer recommended). 8. Margins 16dp; switches, checkboxes, radios, text fields (outlined or filled) → Material; lists use few dividers and no chevrons. 9. Style: color roles, Roboto (or brand font), SF Symbols → Material Symbols (Google Fonts; see the icon policy in the build-android skill), Material motion (ripple, container transform, shared axis, fade through). 10. Rewire the prototype (up vs back). [TR]


### SF Symbol glyphs
- **Blank SF Symbol glyphs:** when the Android mode swaps the font to Roboto, SF Symbol private-use glyphs (U+F0000+) render blank. Find visible TEXT with those code points whose font isn't SF Pro; detach the outermost instance ancestor (re-find the glyph after each detach — node ids change), insert a Material Symbol icon at the glyph's index, size to the container, copy the glyph's fills to the icon vectors, remove the glyph. Mapping used: play U+100284 → `play_arrow_filled` `1b416f8a…`, share U+100202 → `share`, ellipsis U+100360 → `more_vert`, chevron U+10018A → `chevron_forward` `ef4c212c015c4d3bdabb2cca5075bfffa7022dd3`, chevron.down U+100188 → `keyboard_arrow_down` (not a person icon; `person` is `69a0a644672a0016e85c4559795faa6a281f751e`), clock U+100431 → `timer` (driving time; `schedule` `e83c96c7856b0418ed4d0edd2c6706be845164d2` for a time of day), distance U+101577 → Material Symbol `route`, speed U+101417 → `speed` (create them locally from Material Symbols — see the icon policy). Also in the kit: `more_horiz` `59e9a919748e34d7ec272d73644d115c92e652b3`, `arrow_right` `2212456a9a498f8c381ef75c9b27f31e5a76381d`.
- **All SF Symbols → Material Symbols (Android look):** apply the same detach-and-replace to every visible SF glyph, not only blank ones. Set `figma.skipInvisibleInstanceChildren = false` when searching, or glyphs inside instances are missed. Extra mapping: chevron.down U+100188 → `keyboard_arrow_down` `cdc7572de99e38da3c0db2ce459ff13dfc8ac9ad`; xmark U+100184 → `close`; checkmark U+100185 → `check` `911b8adee010a6207cb66a1e26296b6dacfd6818`; chevron.up.chevron.down U+10018F → `arrow_drop_down` `d2547873f01e49c6d52afbe1d816ff21c8f8f95d`; chevron.backward/forward U+100BF6/U+100BFB → `chevron_backward` `30a1e0a0b6929350c8e9413b23cc28d4152b4a7c` / `chevron_forward`; person U+10026A → `person`; pencil U+10169B → `edit` `452979286e0ab19ef7eecb057dfd10215fdaf9e3`; trash U+100211 → `delete` `c70e73bed35cbcf92c22c34dfe3cda457b796ca1`; location U+1003AB → `location_on`; photo U+10031E → `photo` `ff2e51572360eafcdf2e7b2ea55c447eea725ea4`; car U+100658 → `directions_car`; filter U+100306 → Material Symbol `filter_list`; U+100C11 (recap banner) → `chevron_forward`.
