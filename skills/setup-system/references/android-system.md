# Android system (Material 3)

- **Colour:** generate with `scripts/theme-generate.mjs <#brand> tonal` (Tonal Spot = Material Theme Builder default; `fidelity` ≈ "Color Match"). Paste the JSON into `scripts/apply-theme.js` PARAMS.THEME. Collection `M3 Theme · <Product> (<#brand> · Tonal Spot)`, modes Light / Dark, variables `Schemes/<Role>` (49 roles), `Source/Brand` (reference only). Background and rules: `theming-contrast.md`.
- **Brand override:** `node theme-generate.mjs <#brand> tonal --override-light-primary` keeps the exact brand on Light Primary and adds `primaryTextLight/Dark` → `Custom/Primary Text` for brand-coloured text/icons. The output also gives `brandOnWhite` (contrast of a white label) and `accessibleHex` (closest tone passing 4.5:1) — report both.
- **Type:** `scripts/type-scale.js` with PLATFORM `android`, PREFIX `<Product>/M3`, fonts from the person's answer. Display/headline/title use the title font; body/label the body font; headline/title/label emphasized (medium weight). Modes 100% / 200% (Android 14 non-linear scaling; see `text-scaling.md`).
- **Icons:** Material Symbols Outlined, weight from the decision (default 600), filled variant for selected states. `npm pack @material-symbols/svg-600` (or svg-400/500), convert with `scripts/svg-to-24.py`, build components with `createIconComponent` (build-android skill) into one frame `_Icons · Material Symbols (Outlined <weight> · filled for selected)`; combine as a component set `Material Symbols` with properties `Icon` and `Style` (Outlined/Filled). Record name → component id in the saved system.
- **Developer handoff:** Compose `lightColorScheme(...)` / `darkColorScheme(...)` from the same JSON; text sizes and line heights in sp.
